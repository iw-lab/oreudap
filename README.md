# 오르답 — 정답을 밟고 오르는 무한 학습 계단

구구단과 영단어를 **한눈에 즉답**하며 층을 올리는 세로형 아케이드 학습 게임.
위로 갈라지는 발판마다 답이 적혀 있고, **맞는 답을 밟아야만 한 층 오른다.**

▶ **플레이: https://muhan-61w.pages.dev**

## 설계의 중심 한 줄
학습을 «진행의 1차 자원»으로 둔다. 시간은 벽이고 정답이 열쇠다.
그래서 실력이 곧 기록이 된다 — 실측(게임 코어를 직접 돌린 봇 격자):

| 아는 확률 | 0(순수 찍기) | 0.6 | 0.9 | 1.0 |
|---|---|---|---|---|
| 중앙값 층 | 3 | 10 | 86 | 200 |

찍기·연타·정답 위치 카운팅으로는 오를 수 없다(게이트가 매번 확인한다).

## 아이를 위한 원칙
- **개인정보를 아예 받지 않는다.** 이름·나이·학교·계정·채팅 없음, 입력 필드 0개,
  광고·분석 SDK 0개, 외부 도메인 요청 0건. 기록은 이 기기 localStorage 에만 남는다.
- 오답은 벌이 아니다. 틀리면 **정답 발판을 알려 주고** 오답노트에 담아 며칠 뒤 다시 낸다.
- 코인으로 파는 것은 캐릭터·하늘 같은 **코스메틱뿐**. 돈으로 학습을 건너뛸 수 없다.

## 만든 방식
- **엔진**: Phaser 3.90 (월드만 캔버스) + **DOM 오버레이**(글자·터치 타깃)
  → 44px 터치·28px 글자·대비 4.5:1 을 «실제로 잴 수 있다». 캔버스 오브젝트로는 증명이 불가능하다.
- **코어**(`src/core/`)는 DOM·Phaser 를 import 하지 않는다 → 브라우저 없이 완료 기준을 1:1 테스트.
- **에셋 전부 자체 제작**: 이미지 15장(Meta 생성 후 후처리), 효과음 7종(오프라인 렌더),
  BGM 1곡(ACE-Step 로컬, 이음새 없는 루프). 외부 폰트·CDN 0개. 원장 = `public/assets/asset-license.json`.

## 개발
```bash
npm install
npm run dev        # 개발 서버
npm run gate       # 전체 게이트 14종 (배포 전 이것만 돌리면 된다)
npm run assets     # 에셋 재생성 + 라이선스 원장
npm run docs:sync  # GDD 수치표를 게임 코드에서 재생성
```

## 여정 · 오늘의 계단 (2026-09-06)

한 판이 끝나면 갈 곳이 없던 것을 고쳤다. 비슷한 게임 **18종**을 조사해 골랐다 —
전문·출처·근거 = `docs/RESEARCH-retention.md`.

- **🗺️ 여정** — 계단을 이름 있는 구간으로 나눈다(숲 1~20 · 구름 21~50 · 우주 51~90 · 용암 91~).
  해금은 **코인이 아니라 도달 층**이고, **과목마다 따로** 진행한다.
  해금 상태를 저장하지 않고 최고 기록에서 매번 유도한다 — 위조할 값이 없으면 위조가 없다(D38).
- **📅 오늘의 계단** — 날짜가 시드다. 서버도 계정도 없이 **전국 어디서나 같은 판**이 나온다(D37).
  목표층·오늘의 규칙·별 3개. 하루 최고 결과만 깃발로 남는다.
- **🗓️ 이번 주 도장** — **연속이 아니라 누적**이다. 하루 빠져도 앞 도장이 사라지지 않는다.
- **📊 숙련도** — 단별·밴드별 정답률. 남과 겨루는 축(등수판)과 분리된 「어제의 나」 축.
- **결과 화면** — 성격이 다른 목표를 셋 이상 겹쳐 보여 주고, **그만두는 길을 먼저 제시**한다(D40).

🔴 **넣지 않은 것**: 깨지면 0이 되는 연속 출석 · FOMO 카운트다운 · 가챠 · 실패 직후 부활 유도 ·
에너지 고갈 대기. OECD 아동 다크패턴 지적이 근거이고, **D39 가 화면 문구를 기계로 검사**한다.
