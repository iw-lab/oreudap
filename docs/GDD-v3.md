# 오르답 v3 — «한 발 집중» 업그레이드 (2026-10-23)

> 사용자: «목숨이 너무 많아서 긴장감이 덜해. 무한의 계단류는 한 번 틀리면 떨어지니까 집중해야 하는 거 아니야?
> 계단이 연결되면 좋겠는데. 비슷한 류 게임의 인기·재미 지점을 넣어줘.»

## 1. 바뀐 규칙

| 모드 | v2 | v3 |
|---|---|---|
| 무한 오르기 | 하트 3 · 10연속마다 하트 +1 | **한 번 틀리면 추락** · 다시 일어서기 1번 |
| 아슬아슬 | 오답 = 기력 −0.30 | 기력 게이지 + **오답이면 추락** · 다시 일어서기 1번 |
| 거울 계단 | 하트 3 | 무한 오르기와 같다 |
| 60초 질주 | 하트 5 | 오답이면 **한 칸 미끄러짐 + 2초 감점**(시간으로만 끝남) |
| 오늘의 계단 | 목표 30~70층 | 목표 **15~35층**(추락형에 맞춰 낮춤) |

수치의 정본은 `src/core/balance.js`(`MODES` · `REVIVE` · `FEVER` · `CLOSE_CALL`)다.

## 2. 비슷한 게임에서 가져온 재미 지점

| 인기 요인 | 어디서 | 오르답에서는 |
|---|---|---|
| 한 번의 실수가 판을 끝낸다 → 집중 | 무한의 계단 · Flappy Bird · Piano Tiles | 오답·시간초과 한 번이면 추락. 캐릭터가 계단 아래로 굴러떨어진다 |
| 판마다 한 번 «이어하기» | 대부분의 캐주얼 아케이드(광고·보석 부활) | **다시 일어서기**: 광고·보석 대신 «방금 놓친 문제부터 3문제 연속 정답». 긴장은 그대로, 오답은 그 자리에서 다시 꺼내 보는 복습이 된다 |
| 끊기지 않는 길, 리듬 | 계단·러너 장르 공통 | **이어지는 계단**: 다음 갈래가 밟은 발판 바로 위 옆에 붙어 나오고, 세계가 옆으로도 흘러 지나온 길이 한 줄기 계단으로 남는다 |
| 연속 성공 보상(피버) | 쿠키런 질주 · 리듬게임 콤보 | **불꽃 계단**: 10연속부터 발판이 달아오르고 코인 2배. 한 번 틀리면 꺼진다 |
| 아슬아슬하게 해냈다는 쾌감 | Crossy Road의 아슬아슬한 순간 · 타이밍 게임 | 제한시간 75%를 넘겨 맞히면 «간발!» |
| 내 기록에 도전 | Flappy Bird의 최고 점수 · Doodle Jump의 기록 표시 | 최고 기록 높이에 **깃발**이 미리 떠 있고, 3층 남았을 때부터 «최고 기록까지 N층!» |
| 찍어서는 못 이긴다 | 퀴즈 아케이드 공통 | 질주 오답은 한 칸 미끄러진다. 2갈래를 찍으면 오르내림이 반반이라 기댓값이 0이 된다 |

## 3. 저작권·표현 차별화 (RESEARCH §3 갱신)

«한 번 틀리면 떨어진다», «이어지는 계단», «부활 1회»는 장르 전반의 아이디어 층위다.
무한의 계단과 **겹치지 않게 지킨 것**은 다음과 같다.

- **입력**: 오르기/방향전환 2버튼 토글이 없다. 정답이 적힌 갈래 발판을 직접 누른다.
- **계단 형태**: 지그재그 한 줄 벽돌 계단이 아니다. 밟은 발판 위로 2~3갈래가 «갈라져» 나오고 정답 갈래만 남는다.
- **부활**: 광고나 재화가 아니라 학습 과제로 부활한다.
- **그림·캐릭터·제목**: 모두 자체 제작이다. 제목에는 «무한»과 «계단»을 함께 쓰지 않는다(D41).
