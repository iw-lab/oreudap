## 1-1. 개요 (변경분)
- 한 줄 컨셉 그대로: **정답 발판을 밟아야만 한 층 오른다.**
- v2 목표: ① 기본틀(학교 대항·전체화면·모드 카드·심플 UI) ② 그래픽 리마스터(3D 리그 캐릭터·구간별 세계) ③ PC 최적화 적응형 화면 ④ 개인정보 «안 받기»로 정리 ⑤ 반응 강화.
- 🚫 **이용권 없음**(사용자 결정 2026-10-13): 키트를 `--free-play` 로 깐다 — 판 자체가 문제 풀이라 «문제 풀고 이용권» 화면을 건너뛰고, 판 영수증·학교 점수 정산만 쓴다.

## 1-2. 코어 루프 — 변경 없음 + 학교 대항 메타 추가
```
[과목 고르기] → [모드 카드] → 판(정답 발판 밟기) → 결과 → 「우리 학교 +N점」 → 첫 화면 학교 순위 갱신
```
- 학교 점수 = 판 결과(층수 구간) → 허브 정산. 하루 상한·환불 창은 키트 규약 그대로.

## 1-5. UI/UX — 적응형 다시 짜기
**첫 화면(기본틀 셸)**
```
┌ 머리줄: ▲오르답 로고 ─────────── [전체화면] [설정] ┐
│ ① 학교 순위(오늘/이번 주 · 상위 5 + 우리 학교) — 맨 위·접지 않음 │
│ ② 과목 고르기(가로 칩 5개: 구구단·영단어 3·4·5·6·국어 3·4·5·6) │
│ ③ [시작하기] 주 단추 딱 1개(고른 과목 · 고른 모드)          │
│ ④ 모드 카드 5장(같은 모양·같은 높이·설명 한 줄)              │
│ ⑤ 보조 줄: 나의 여정 · 오답노트 · 컬렉션 · 오늘의 등수        │
└──────────────────────────────────────────────┘
```
- **PC(≥1024px)**: 2단 — 왼쪽 ①②③④, 오른쪽 «나의 여정 + 오늘의 계단 + 이번 주 도장». 최대 폭 1200px.
- **태블릿(600~1023)**: 1단, 모드 카드 3열. **모바일(<600)**: 1단, 모드 카드 2열, 글자 ≥12px · 누르는 곳 ≥44px.
- **플레이 화면 PC**: 가운데 게임 판(세로 비율 유지) + 왼쪽 패널(과목·모드·하트/기력·시계) + 오른쪽 패널(층·최고 기록까지 N층·연속). 모바일은 지금처럼 판 위에 HUD.
- 시작 단추 → **자동 전체화면**(제스처 안), 게임 상단에도 전체화면 단추.
- 아이콘 전부 **자체 호스팅 SVG**(lucide-static, 버전 고정·고지 포함). 과목 아이콘·여정 구간 아이콘은 생성 그림.
- 색·글꼴은 기존 남색 밤하늘 + 금색 강조 토큰을 `--gb-accent`/`--gb-bg` 로 옮긴다(디자인 게이트 FAIL 0).

**개인 등수판 없앰 → 학교 랭킹만**(사용자 결정 2026-10-13 «학교랭킹으로 하자»): «오늘의 등수»(이름·층수 개인 판)와 이름 입력칸을 통째로 뺀다. 순위는 기본틀 학교 순위 하나뿐 — 아이 이름이 화면·서버 어디에도 없다. 옛 등수 워커로 보내던 제출도 끊는다(워커는 옛 주소 호환용으로 남겨 두되 클라이언트 호출 0).
